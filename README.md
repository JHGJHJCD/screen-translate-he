# תרגום מסך (אנגלית ← עברית)

ריבוע עם מסגרת אדומה שיושב מעל המסך. גוררים אותו מעל טקסט באנגלית, והעברית מופיעה במקום האנגלית.

## התקנה

מורידים את `ScreenTranslateSetup.exe` מ[הגרסה האחרונה](https://github.com/JHGJHJCD/screen-translate-he/releases/latest) ומפעילים.

- Windows 10 (גרסה 2004 ומעלה) או Windows 11, 64 ביט.
- צריך ששפת English תהיה מותקנת ב-Windows (לזיהוי הטקסט).
- הקובץ חתום בתעודה עצמית, לכן Windows יציג אזהרה בהפעלה הראשונה ("מידע נוסף" ← "הפעל בכל זאת").
- הסרה: הגדרות ← אפליקציות ← "תרגום מסך".

## שימוש

- `Ctrl+Alt+T` מציג ומסתיר את הריבוע. מסגרת אדומה = עובד, ירוקה = התרגום מוצג.
- התוכנה נשארת ליד השעון; יציאה אמיתית מהתפריט של הסמל שם.
- פעם ביום היא בודקת כאן אם יצאה גרסה חדשה, ומתקינה אותה רק אם מאשרים.

## פרטיות

הטקסט שמתחת לריבוע מזוהה במחשב עצמו ונשלח ל-Google Translate לתרגום. התמונה של המסך לא יוצאת מהמחשב.
לא כדאי להניח את הריבוע מעל סיסמאות או מידע רגיש.

## למפתחים

Python 3.12 ו-PyQt6. `python main.py` מריץ, `python build_share.py` בונה את קובץ ההתקנה (PyInstaller + Inno Setup 6),
`python tests/test_units.py` מריץ את בדיקות היחידה.

הפרטים המלאים (התקנת הספריות, מבנה הקוד, בדיקות) ב-[CONTRIBUTING.md](CONTRIBUTING.md), והמשימות הפתוחות ב-[Issues](https://github.com/JHGJHJCD/screen-translate-he/issues).
